# Güvenlik Politikası

## Desteklenen sürümler

Proje aktif geliştirme aşamasındadır; güvenlik düzeltmeleri `main` dalına uygulanır.

## Açık bildirimi

Bir güvenlik açığı bulursanız lütfen **herkese açık issue açmayın**. Bunun yerine depo sahibiyle GitHub üzerinden özel olarak iletişime geçin. Bildiriminizde şunları paylaşırsanız hızlıca değerlendirebiliriz:

- Etkilenen bileşen (Wear OS uygulaması / iOS companion)
- Açığı tetikleyen adımlar
- Olası etki

Makul bir sürede yanıt vermeye çalışırız.

## Kapsam

WatchBridge tüm veriyi cihazda işler; sunucu veya bulut bileşeni yoktur. Bluetooth LE / ANCS katmanındaki açıklar önceliklidir.
